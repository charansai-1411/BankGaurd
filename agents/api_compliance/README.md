# API Compliance Agent — Context & Specifications

This agent evaluates API schemas, structures, configurations, and data transport policies against RBI API-specific security and operational regulations.

---

## 1. Goal
To audit OpenAPI documentation (endpoints, query parameters, payloads, headers) for missing security schemas, unencrypted channels, or non-compliant routing.

---

## 2. Operations
* **Primary Source Ingest**: RBI regulations concerning API integrations, data security, and communication protocols.
* **Vector Search Target**: Ingested and flattened bank OpenAPI specification endpoints (namespace: `api_specs_bank_doc`).
* **OpenAPI Specific Tools**:
  * **OpenAPI Validator Tool**: Validates specs against standard rules and compliance schemas.
* **Delegation Capabilities**:
  * Delegates code verification (e.g., actual validation of input payloads, logging filters, cryptographic functions) to the **Codebase Agent**.

---

## 3. Important to Remember
> [!NOTE]
> - **Metadata Mapping**: Flattened OpenAPI specs contain `endpoint_path` metadata. Findings generated by this agent should directly reference endpoints (e.g. `POST /payments`) to preserve compliance mapping clarity.
